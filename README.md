# TeleVIP — Graph Messenger compatibility build

This repository is prepared for a GitHub Actions Android build.

## Source archive
Upload `tele-GraphMessenger-13.2.2.2-source.zip` to the repository root. The workflow extracts it and runs the release build.

The resulting APK is published as a workflow artifact. This compatibility build is not yet runtime-verified on Graph Messenger 13.2.2.2.
